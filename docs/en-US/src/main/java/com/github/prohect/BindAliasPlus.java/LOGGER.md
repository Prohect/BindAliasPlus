# LOGGER field (src/main/java/com/github/prohect/BindAliasPlus.java)

## Syntax

```java
public static final org.slf4j.Logger LOGGER
```

## Remarks

SLF4J logger instance named after `MOD_ID` (`"bind-alias-plus"`).
Used by `onInitialize()` to emit a startup greeting.

Also referenced by `BindAliasPlusClient.LOGGER` (a separate instance with the same name).

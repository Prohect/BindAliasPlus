# PickItemAlias

One-shot alias that triggers vanilla pick-block behavior. Picks the block or entity the player is looking at onto the hotbar.

## Fields

_No public/protected fields._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Fires `keyPickItem` keybinding to trigger `pickBlockOrEntity()` |

# YawAlias

Builtin alias for relative yaw rotation (horizontal turning). Usage: `yaw\deg` where `deg` is the relative angle in degrees.

## Fields

_No public/protected fields (inherits `flag` from `BuiltinAliasWithDoubleArgs`)._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Rotate yaw by the parsed double value |

# SendCommandAlias

Builtin alias that sends a server command. Usage: `sendCommand\command` (no leading `/`).

## Fields

_No public/protected fields._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Send `args` as a command via `sendCommand()` |

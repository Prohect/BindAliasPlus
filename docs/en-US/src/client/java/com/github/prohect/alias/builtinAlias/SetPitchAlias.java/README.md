# SetPitchAlias

Builtin alias for absolute pitch setting. Usage: `setPitch\deg` where `deg` is the target pitch angle.

## Fields

_No public/protected fields (inherits `flag` from `BuiltinAliasWithDoubleArgs`)._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Set pitch to the absolute double value |

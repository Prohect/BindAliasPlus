# SetPerspectiveAlias

Builtin alias that sets the camera perspective. Usage: `builtinSetPerspective\N` (0=FPS, 1=TPS, 2=TPS2).

## Fields

_No public/protected fields (inherits `flag` from `BuiltinAliasWithIntegerArgs`)._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Set camera to perspective 0/1/2 with FPS↔TPS camera-entity update |

# UseAlias

Switch alias for using items / interacting with blocks (right-click). Usage: `+use` / `-use`. Manually parses boolean args.

## Fields

_No public/protected fields._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Manual switch on "0"/"1": press/release use key |

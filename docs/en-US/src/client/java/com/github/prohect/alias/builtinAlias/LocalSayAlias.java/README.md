# LocalSayAlias

String-arg alias that displays a client-side-only chat message. The text is visible locally on the HUD and in the chat channel but is never sent to the server.

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `LocalSayAlias run(String args)` | Add `args` as a client-side system message to the local chat |

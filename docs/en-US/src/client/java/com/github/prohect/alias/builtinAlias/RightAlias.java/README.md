# RightAlias

Switch alias for strafe-right movement. Usage: `+right` / `-right`. Mirrors `LeftAlias` for the opposite direction.

## Fields

_No public/protected fields (inherits `flag` from `BuiltinAliasWithBooleanArgs`)._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Parse +/- args: 1=press right key, 0=release |

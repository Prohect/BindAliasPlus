# UnloadUserAllAlias

Convenience alias that removes all runtime-created items (aliases + keybindings + variables). Usage: `unloadUserAll`.

## Fields

_No public/protected fields._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Run all three user unload operations with a single summary log |

# SetYawAlias

Builtin alias for absolute yaw setting. Usage: `setYaw\deg` where `deg` is the target yaw angle.

## Fields

_No public/protected fields (inherits `flag` from `BuiltinAliasWithDoubleArgs`)._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Set yaw to the absolute double value |

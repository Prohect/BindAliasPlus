# SneakAlias

Switch alias for sneaking/crouching. Usage: `+sneak` / `-sneak`.

## Fields

_No public/protected fields (inherits `flag` from `BuiltinAliasWithBooleanArgs`)._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Parse +/- args: 1=press sneak key, 0=release |

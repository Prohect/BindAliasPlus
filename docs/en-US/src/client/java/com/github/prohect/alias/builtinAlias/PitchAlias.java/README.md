# PitchAlias

Builtin alias for relative pitch rotation. Usage: `pitch\deg` where `deg` is the relative angle in degrees.

## Fields

_No public/protected fields (inherits `flag` from `BuiltinAliasWithDoubleArgs`)._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Rotate pitch by the parsed double value |

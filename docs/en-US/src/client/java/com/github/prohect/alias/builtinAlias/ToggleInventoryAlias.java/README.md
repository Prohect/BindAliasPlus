# ToggleInventoryAlias

One-shot alias that toggles the player inventory screen. Usage: `toggleInventory`.

## Fields

_No public/protected fields._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Toggle: open inventory if no screen, close if container screen open |

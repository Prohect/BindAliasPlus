# ScreenshotAlias

Switch alias that takes a Minecraft screenshot on the press event. Usage: `+screenshot` (release `-screenshot` is no-op).

## Fields

_No public/protected fields (inherits `flag` from `BuiltinAliasWithBooleanArgs`)._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | On flag=1: take screenshot via `ScreenshotRecorder.saveScreenshot()` |

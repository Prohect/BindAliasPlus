# key method (src/client/java/com/github/prohect/KeyPressed.java)

## Syntax

```java
public com.mojang.blaze3d.platform.InputConstants$Key key()
```

## Remarks

Record accessor returning the `InputConstants.Key` that triggered this event.
Never null (annotated `@NotNull`). The key can be a keyboard key
(e.g., `key.keyboard.f`) or a mouse button (e.g., `mouse1`).

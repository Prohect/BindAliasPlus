# UnloadCFGBindsAlias

One-shot alias that removes CFG-loaded keybindings and cleans up associated aliases. Usage: `unloadCFGBinds`.

## Fields

_No public/protected fields._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Remove bindings from `BINDING_PLUS` where `fromCFG() == true` |

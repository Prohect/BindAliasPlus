# aliasName field (src/client/java/com/github/prohect/alias/AliasRecord.java)

## Syntax

```java
public String aliasName()
```

## Return value

The name of the alias to look up in the global registration maps.

## Remarks

This is a record component accessor (auto-generated by Java `record`). The value is set at construction time and never changes — `AliasRecord` is immutable.

When `UserAlias.decodeArgs2Alias()` parses a definition like `slot\3`, the first token (`"slot"`) becomes the `aliasName`. `UserAlias.run()` then uses this name to look up the alias in `Alias.aliasesWithoutArgs`, `Alias.aliasesWithArgs`, etc.

# ShutdownAlias

One-shot alias that cleanly shuts down the game. Usage: `builtinShutdown`.

_No public/protected fields._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Call `Minecraft.stop()` to exit the game |

# LOGGER field (src/client/java/com/github/prohect/BindAliasPlusClient.java)

## Syntax

```java
public static final org.slf4j.Logger LOGGER
```

## Remarks

SLF4J logger instance for the client source set. Named `"bind-alias-plus"` (same
name as the common-side logger in `BindAliasPlus`, but a separate instance).

Used for warnings and errors during config parsing, key parsing, and command execution.

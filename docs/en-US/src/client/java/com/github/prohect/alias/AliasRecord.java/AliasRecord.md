# AliasRecord (src/client/java/com/github/prohect/alias/AliasRecord.java)

## Syntax

```java
public final class com.github.prohect.alias.AliasRecord extends java.lang.Record
```

## Static Initializer

_None._

## Remarks

A Java `record` that represents a single parsed alias entry: an alias name and its
arguments string.

Instances are created by `UserAlias.decodeArgs2Alias()` and enqueued into the
`UserAlias.aliases` deque. During dispatch (`UserAlias.run()` / `runInternal()`),
entries are dequeued one by one: `aliasName` is used to look up the alias
implementation in the static registries, and `args` is passed to `Alias.run()`.

For built-in aliases with args, `args` contains the parameter string (e.g., `"1"`
for a key-down event). For aliases without args or user aliases, `args` is an
empty string.

Being a record, `equals`, `hashCode`, and `toString` are auto-generated by the
compiler.

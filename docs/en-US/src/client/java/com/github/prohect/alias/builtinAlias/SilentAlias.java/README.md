# SilentAlias

Switch alias that toggles silent mode (suppress mod feedback messages). Usage: `+silent` / `-silent`.

## Fields

_No public/protected fields (inherits `flag` from `BuiltinAliasWithBooleanArgs`)._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Set `BindAliasClient.silentMode` to true/false |

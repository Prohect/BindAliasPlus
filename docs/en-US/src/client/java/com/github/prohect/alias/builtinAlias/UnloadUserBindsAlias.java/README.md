# UnloadUserBindsAlias

One-shot alias that removes runtime-created keybindings and cleans up associated aliases. Usage: `unloadUserBinds`.

## Fields

_No public/protected fields._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Remove bindings from `BINDING_PLUS` where `!fromCFG()` |

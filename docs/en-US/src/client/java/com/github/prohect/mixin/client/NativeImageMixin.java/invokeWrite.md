# invokeWrite method (src/client/java/com/github/prohect/mixin/client/NativeImageMixin.java)

## Syntax

```java
@Invoker("write")
abstract boolean invokeWrite(java.nio.channels.WritableByteChannel channel) throws java.io.IOException
```

## Parameters

| Name | Type | Description |
|------|------|-------------|
| `channel` | `java.nio.channels.WritableByteChannel` | The channel to write PNG data into |

## Return value

`true` if the PNG was written successfully; `false` otherwise.

## Remarks

An access-widened invoker generated by Mixin's `@Invoker` annotation. It bridges to the private `NativeImage.write(WritableByteChannel)` method, which encodes the image data as a PNG stream.

**Yarn vs. Mojang naming:** In Yarn mappings, the private PNG encoder is named `write`. In Mojang mappings, the same method is named `writeToChannel`. The `@Invoker("write")` string must match the Yarn method name on this branch. On Mojang-mapped branches the annotation reads `@Invoker("writeToChannel")` and the invoker method is named `invokeWriteToChannel`.

This invoker is used by [onWriteTo](onWriteTo.md) to capture raw PNG bytes into a `ByteArrayOutputStream` backed by a `WritableByteChannel`, avoiding filesystem I/O for MCP screenshot requests.

# OpenInventoryAlias

Switch alias that opens or closes the player inventory screen via `+openInventory` / `-openInventory`.

## Fields

_No public/protected fields (inherits `flag` from `BuiltinAliasWithBooleanArgs`)._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Parses +/- args: 1=open inventory screen, 0=close container screen |

# flag field (src/client/java/com/github/prohect/alias/BuiltinAliasWithDoubleArgs.java)

## Syntax

```java
public double flag
```

## Remarks

The parsed `double` value set by `parseArgs()`.

Defaults to `0.0` if parsing fails (unresolved variable and `NumberFormatException`).
Public so subclasses can read the parsed value directly.

# SlotAlias

Builtin alias that selects a hotbar slot. Usage: `slot\N` where N is 1-9 or a variable.

## Fields

_No public/protected fields._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Resolve slot number, validate 1-9, set selected slot client+server |

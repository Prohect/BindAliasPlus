# UnloadCFGVarsAlias

One-shot alias that removes CFG-loaded general variables. Usage: `unloadCFGVars`. Container slot variables are NOT cleaned.

## Fields

_No public/protected fields._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Remove variables from `GENERAL_VARIABLES` and `CFG_VARIABLES` for all CFG-tracked names |

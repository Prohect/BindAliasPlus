# PlayerListAlias

Switch alias that shows the online-player overlay (Tab) while held. Usage: `+playerList` / `-playerList`.

## Fields

_No public/protected fields (inherits `flag` from `BuiltinAliasWithBooleanArgs`)._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Parse +/- args: 1=press player-list key, 0=release |

# UnloadCFGAllAlias

Convenience alias that removes all CFG-loaded items (aliases + keybindings + variables). Usage: `unloadCFGAll`.

## Fields

_No public/protected fields._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Run all three CFG unload operations with a single summary log |

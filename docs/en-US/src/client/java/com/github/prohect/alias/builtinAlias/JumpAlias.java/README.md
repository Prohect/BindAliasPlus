# JumpAlias

Switch alias for the vanilla jump key binding (keyJump / spacebar). Inherits the `+name`/`-name` pattern from `BuiltinAliasWithBooleanArgs`.

## Fields

| Name | Type | Description |
|------|------|-------------|
| _(none beyond `BuiltinAliasWithBooleanArgs.flag`)_ | `boolean` | Inherited: true for `+jump`, false for `-jump` |

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `JumpAlias run(String args)` | Press or release `options.keyJump`; suppresses press on text-input screens only |

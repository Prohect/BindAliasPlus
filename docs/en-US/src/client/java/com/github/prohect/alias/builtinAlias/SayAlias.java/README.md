# SayAlias

Builtin alias that sends a chat message to the server. Usage: `say\text` or `say\"multi word text"`.

## Fields

_No public/protected fields._

## Methods

| Name | Signature | Description |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | Send `args` as a chat message via `sendChat()` |

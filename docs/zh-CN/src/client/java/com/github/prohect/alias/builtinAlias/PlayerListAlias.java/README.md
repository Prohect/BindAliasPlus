# PlayerListAlias

按住时显示在线玩家浮层（Tab）的开关别名。用法：`+playerList` / `-playerList`。

## 字段

_无公共/受保护字段（从 `BuiltinAliasWithBooleanArgs` 继承 `flag`）。_

## 方法

| 名称 | 签名 | 说明 |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | 解析 +/- 参数：1=按下玩家列表键，0=松开 |

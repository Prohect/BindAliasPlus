# SlotAlias

选择快捷栏槽位的内置别名。用法：`slot\N`，其中 N 为 1-9 或变量。

## 字段

_无公共/受保护字段。_

## 方法

| 名称 | 签名 | 说明 |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | 解析槽位编号，验证 1-9，在客户端和服务端设置所选槽位 |

# hashCode 方法（src/client/java/com/github/prohect/alias/AliasRecord.java）

## 语法

```java
public final int hashCode()
```

## 返回值

由 `aliasName` 和 `args` 两个组件计算出的哈希码。

## 备注

由 Java `record` 实现自动生成。与 `equals` 一致——两个相等的 record 产生相同的哈希。

# YawAlias

用于相对偏航角旋转（水平转向）的内置别名。用法：`yaw\deg`，其中 `deg` 是以度为单位的相对角度。

## 字段

_无公共/受保护字段（从 `BuiltinAliasWithDoubleArgs` 继承 `flag`）。_

## 方法

| 名称 | 签名 | 说明 |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | 按解析出的 double 值旋转偏航角 |

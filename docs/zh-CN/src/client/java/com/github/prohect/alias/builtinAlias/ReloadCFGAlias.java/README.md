# ReloadCFGAlias

在运行时重新加载配置文件的一次性别名。用法：`reloadCFG`。

## 字段

_无公共/受保护字段。_

## 方法

| 名称 | 签名 | 说明 |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | 调用 `BindAliasClient.loadCFG()` 重新加载配置 |

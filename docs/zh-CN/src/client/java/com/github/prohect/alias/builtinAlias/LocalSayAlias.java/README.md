# LocalSayAlias

显示仅客户端侧聊天消息的字符串参数别名。文本在本地 HUD 和聊天频道中可见，但绝不会发送到服务器。

## 字段

| 名称 | 类型 | 说明 |
|------|------|-------------|
| _（除继承外无）_ | | |

## 方法

| 名称 | 签名 | 说明 |
|------|-----------|-------------|
| [run](run.md) | `LocalSayAlias run(String args)` | 将 `args` 作为客户端侧系统消息添加到本地聊天界面 |

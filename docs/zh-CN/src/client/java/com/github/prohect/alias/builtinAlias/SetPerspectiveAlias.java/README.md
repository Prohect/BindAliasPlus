# SetPerspectiveAlias

设置相机视角的内置别名。用法：`builtinSetPerspective\N`（0=FPS，1=TPS，2=TPS2）。

## 字段

_无公共/受保护字段（从 `BuiltinAliasWithIntegerArgs` 继承 `flag`）。_

## 方法

| 名称 | 签名 | 说明 |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | 将相机设置为视角 0/1/2，并进行 FPS↔TPS 相机实体更新 |

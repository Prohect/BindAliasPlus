# CyclePerspectiveAlias

按 FPS → TPS → TPS2 顺序循环相机视角的一次性别名。无参数——每次调用使相机前进一步。

## 字段

| 名称 | 类型 | 说明 |
|------|------|-------------|
| _（除继承外无其他）_ | | |

## 方法

| 名称 | 签名 | 说明 |
|------|-----------|-------------|
| [run](run.md) | `CyclePerspectiveAlias run(String args)` | 通过 `CameraType.cycle()` 循环相机类型并更新相机实体 |

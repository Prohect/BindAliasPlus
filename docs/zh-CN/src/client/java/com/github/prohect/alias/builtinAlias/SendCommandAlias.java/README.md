# SendCommandAlias

发送服务器命令的内置别名。用法：`sendCommand\command`（无前导 `/`）。

## 字段

_无公共/受保护字段。_

## 方法

| 名称 | 签名 | 说明 |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | 通过 `sendCommand()` 将 `args` 作为命令发送 |

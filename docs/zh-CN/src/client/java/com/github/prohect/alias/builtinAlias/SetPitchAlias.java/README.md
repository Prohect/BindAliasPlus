# SetPitchAlias

用于绝对俯仰角设置的内置别名。用法：`setPitch\deg`，其中 `deg` 是目标俯仰角。

## 字段

_无公共/受保护字段（从 `BuiltinAliasWithDoubleArgs` 继承 `flag`）。_

## 方法

| 名称 | 签名 | 说明 |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | 将俯仰角设置为绝对的 double 值 |

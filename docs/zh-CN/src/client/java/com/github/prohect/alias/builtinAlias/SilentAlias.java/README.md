# SilentAlias

切换静默模式（抑制模组反馈消息）的开关别名。用法：`+silent` / `-silent`。

## 字段

_无公共/受保护字段（从 `BuiltinAliasWithBooleanArgs` 继承 `flag`）。_

## 方法

| 名称 | 签名 | 说明 |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | 将 `BindAliasClient.silentMode` 设置为 true/false |

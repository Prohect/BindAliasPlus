# OpenInventoryAlias

通过 `+openInventory` / `-openInventory` 打开或关闭玩家物品栏界面的开关别名。

## 字段

_无公共/受保护字段（从 `BuiltinAliasWithBooleanArgs` 继承 `flag`）。_

## 方法

| 名称 | 签名 | 说明 |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | 解析 +/- 参数：1=打开物品栏界面，0=关闭容器界面 |

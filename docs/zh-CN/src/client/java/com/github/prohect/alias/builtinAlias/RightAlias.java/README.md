# RightAlias

向右侧移移动的开关别名。用法：`+right` / `-right`。镜像 `LeftAlias` 的反向方向。

## 字段

_无公共/受保护字段（从 `BuiltinAliasWithBooleanArgs` 继承 `flag`）。_

## 方法

| 名称 | 签名 | 说明 |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | 解析 +/- 参数：1=按下右移键，0=松开 |

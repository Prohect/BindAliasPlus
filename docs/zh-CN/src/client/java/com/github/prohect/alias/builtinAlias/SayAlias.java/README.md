# SayAlias

向服务器发送聊天消息的内置别名。用法：`say\text` 或 `say\"multi word text"`。

## 字段

_无公共/受保护字段。_

## 方法

| 名称 | 签名 | 说明 |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | 通过 `sendChat()` 将 `args` 作为聊天消息发送 |

# ToggleInventoryAlias

切换玩家物品栏界面的一次性别名。用法：`toggleInventory`。

## 字段

_无公共/受保护字段。_

## 方法

| 名称 | 签名 | 说明 |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | 切换：无界面时打开物品栏，容器界面打开时关闭 |

```java
public T putToAliasesWithArgs_notSuggested()
```

## 返回值

返回 `this`，以支持流畅的构建器链式调用。

## 备注

无键重载——以 `this.builtinAliasName` 作为键，将 `this` 注册到 `Alias.aliasesWithArgs_notSuggested`。在此注册的别名可执行，但从用户建议中隐藏。

# RunAliasAlias

按名称调用另一个别名的内置别名。用法：`builtinRunAlias\name` 或 `builtinRunAlias\name\extraArgs`。

## 字段

_无公共/受保护字段。_

## 方法

| 名称 | 签名 | 说明 |
|------|-----------|-------------|
| [run](run.md) | `run(String args)` | 将参数拆分为名称+额外参数，查找别名，调用 `run(extraArgs)` |
